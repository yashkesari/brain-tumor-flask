# NeuroScan AI 🧠

**Deep Learning Brain MRI Classification, Segmentation, and Diagnostic Triage Platform**

NeuroScan AI is a comprehensive, AI-assisted research prototype designed to analyze Brain MRI scans, extract data from medical reports, and provide clinical symptom triage. It utilizes a dual-stage deep learning pipeline alongside natural language processing to assist in neurological evaluations.

---

## 🌟 Key Features

### 1. Dual-Stage MRI Analysis Engine
* **Classification (CNN)**: A customized TensorFlow Convolutional Neural Network that evaluates MRI scans (JPG/PNG) to classify tissues into 4 categories: **Glioma, Meningioma, Pituitary Tumor, or Normal (No Tumor)**.
* **Instance Segmentation (YOLOv11)**: Integrates Ultralytics YOLOv11 to draw precise bounding boxes and polygon masks around detected lesions, calculating spatial telemetry and pixel density.

### 2. Medical Report Analysis (OCR + NLP)
* Upload existing text or scanned medical/radiology reports (PDF, JPG, PNG).
* Extracts structured text using **PyMuPDF** and **Tesseract OCR**.
* Applies natural language processing to detect the document type, extract key findings, locate anatomical terms, and filter out negated sentences (e.g., "cerebellum is unremarkable").

### 3. Symptom Risk Engine
* An interactive clinical triage questionnaire.
* Users input their current neurological symptoms (e.g., types of headaches, motor weakness, seizures, vision changes).
* The engine calculates a severity score, flags critical warning signs, and outputs a risk level (Minimal, Low, Moderate, High) with targeted medical follow-up recommendations.

### 4. Patient Education Hub
* A dedicated awareness module providing detailed information on tumor subtypes, standard treatments, precautions, and "Dos & Don'ts" tailored to specific classifications.

---

## 🏗️ System Architecture

The application is built on a **Single-Screen Unified Dashboard** that serves as a clinical command center, keeping all modules accessible simultaneously.

* **Frontend**: HTML5, CSS3 (Custom Design System), Vanilla JavaScript.
* **Backend**: Python 3, Flask.
* **AI Models**: TensorFlow/Keras, Ultralytics YOLO.
* **Vision & NLP**: OpenCV, PyTesseract, PyMuPDF.

## ⚙️ Installation & Setup

### Prerequisites
* Python 3.8+
* [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) installed on your system.

### 1. Install Tesseract OCR
**For macOS:**
```bash
brew install tesseract
```
**For Windows:**
Download the installer from [UB-Mannheim](https://github.com/UB-Mannheim/tesseract/wiki) and ensure it is installed at `C:\Program Files\Tesseract-OCR\tesseract.exe`.

### 2. Clone the Repository
```bash
git clone https://github.com/yashkesari/brain-tumor-ai.git
cd brain-tumor-flask
```

### 3. Set Up Virtual Environment (Recommended)
```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### 4. Install Python Dependencies
```bash
pip install -r requirements.txt
```
*(Make sure `pymupdf` and `pytesseract` are installed if not already in your requirements file: `pip install pymupdf pytesseract opencv-python`)*

### 5. Run the Application
```bash
python app.py
```
The application will be available at `http://127.0.0.1:5000/` (or port 5001 depending on your local config).
